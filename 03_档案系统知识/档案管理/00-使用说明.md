# 档案管理学习资料使用说明

这套学习资料由你提供的 16 份档案相关文档整理而成，目标是**帮助理解、记忆和复习**。全部为 Markdown 格式，用 Typora、Obsidian、VS Code 或任意文本编辑器均可打开阅读。

## 一、目录结构

```
档案管理/
├── 00-使用说明.md            ← 本文件（从这里开始）
├── 00-原文提取/               ← 16 份文档的全文提取稿（含 OCR 识别稿）
├── 01-分篇学习笔记/           ← 16 份文档逐一对应的学习笔记
├── 02-专题总览/               ← 5 个跨文档专题（体系、流程、元数据、归档流程、安全备份）
├── 03-记忆辅助/               ← 4 份记忆工具（速记、对比表、自测题、一页总览图）
└── _work/                    ← 处理脚本（提取/OCR 用，可忽略）
```

## 二、建议学习路线（三遍法）

### 第 1 遍：建立框架（30～60 分钟）
按顺序读：
1. [00-使用说明.md](00-使用说明.md)
2. [03-记忆辅助/04-一页总览图.md](03-记忆辅助/04-一页总览图.md) ——先看全景
3. [02-专题总览/01-法律法规与标准体系地图.md](02-专题总览/01-法律法规与标准体系地图.md) ——弄清 16 份文档的关系

### 第 2 遍：逐篇精读（建议每天 2～3 篇）
按编号顺序读 [01-分篇学习笔记](01-分篇学习笔记/) 中的 16 篇笔记。每篇结构统一：
- 文档名片（文号、施行日期）
- 核心概念与定义
- 重点条文/要求（含记忆提示）
- 必背数字速记表

> 提示：先读法规（01～07），再读标准（08～15），最后读软件功能清单（16）。读完每篇，回看对应原文稿查证细节。

### 第 3 遍：强化记忆（复习期）
1. [03-记忆辅助/01-核心概念与数字速记.md](03-记忆辅助/01-核心概念与数字速记.md) ——背定义、数字、口诀
2. [03-记忆辅助/02-易混淆点对比表.md](03-记忆辅助/02-易混淆点对比表.md) ——专攻易错点
3. [03-记忆辅助/03-自测题与答案.md](03-记忆辅助/03-自测题与答案.md) ——先做题再对答案，错题回查笔记
4. [02-专题总览](02-专题总览/) ——按专题二次强化
