# 14 GB/T 11822—2008 科学技术档案案卷构成的一般要求

## 一、标准名片

| 项目 | 内容 |
| --- | --- |
| 发布/实施 | 2008-11-13 发布，**2009-05-01 实施** |
| 代替 | GB/T 11822—2000（首次发布 1989 年） |
| 归口 | 国家档案局提出并归口 |
| 内容 | 科技档案案卷的**组卷原则和方法、案卷及卷内文件排列、案卷编目、装订、卷盒表格规格及制成材料** |
| 适用范围 | 一般科技档案案卷整理；专业性较强和非纸质载体科技档案可**参照**执行 |

## 二、核心术语（第 3 章）

- 科技文件：记录和反映科学研究、生产运营、项目建设活动和设备仪器运行、维护及管理工作的文字、图表、声像等文件材料。
- 科技档案：对国家、社会、本单位和个人具有保存价值、应当归档保存的科技文件。
- 案卷：由**互有联系的若干文件组合而成**的档案保管单位。
- 卷内目录：登录卷内文件题名和其他特征并固定文件排列次序的表格，**排列在卷内文件之前**。
- 卷内备考表：卷内文件状况的记录单。
- 档号：以字符形式赋予档案实体的、用以固定和反映档案排列顺序的一组代码。

## 三、案卷组织（第 4 章）

### 组卷原则
遵循科技文件的**形成规律**，保持案卷内科技文件的**有机联系**和案卷的**成套、系统**，便于档案的**保管和利用**。

### 组卷要求
- 案卷内科技文件**齐全、完整，签章手续完备**；
- 载体和书写印制材料符合档案保护要求。

### 组卷方法（重点）
| 类型 | 方法 |
| --- | --- |
| 管理性文件 | 放入所针对的项目文件中，按**阶段或分年度**组卷 |
| 科研课题、产品、建设项目、设备仪器 | 按**项目、结构、阶段或台（套）**分别组卷 |
| 成册、成套文件 | **保持原有形态** |
| 通用图、标准图 | 可放入相应项目文件或**单独组卷**；其他涉及的项目应在卷内备考表中注明图号和档号 |
| 底图 | 以**张或套**为保管单位整理 |
| 产品局部变更、维修维护文件 | 宜**插卷**放入原案卷，亦可单独组卷排列在原案卷之后并备考表说明 |
| 产品升级换代、项目后评估、改扩建或重建 | **单独组卷排列** |

## 四、案卷和卷内文件排列（第 5 章）——记忆口诀

- 一般原则：**文字材料在前，图样在后；译文在前，原文在后**。
- 管理性文件：按问题结合时间（阶段）或重要程度；**印件在前，定稿在后；正件在前，附件在后；复文在前，来文在后**。
- **科研类案卷六阶段**：课题可行性研究立项 → 方案论证 → 研究实验 → 总结鉴定 → 成果和知识产权申报 → 推广应用。
- **产品类案卷**：产品设计（初步设计、基础设计、技术设计）→ 工艺 → 工装 → 制造 → 定型。
- **建设项目类案卷七阶段**：项目前期 → 项目设计 → 项目施工 → 项目监理 → 项目竣工 → 项目验收 → 项目后评估。
- **设备仪器类案卷**：立项审批 → 开箱验收（自制设备为设计、制造、验收）→ 安装调试 → 随机文件材料 → 运行 → 维护。

## 五、案卷编目（第 6 章）

### 页号
- 以**件**为单位编写页号，以有效内容的页面为一页；
- **已有页号的文件可不再重新编写**；
- **卷内目录、卷内备考表不编写页号**。

### 案卷封面项目（记忆）
档号 + **案卷题名**（产品/课题/项目/设备名称或代字、结构、阶段、文件类型）+ 立卷单位 + 起止日期（年度 4 位数字）+ 保管期限 + **密级（填卷内科技文件的最高密级）**。

- **档号 = 全宗号 + 分类号（或项目代号或目录号）+ 案卷号**。

### 卷内目录项目
序号、文件编号（文号/型号/图号/代字代号）、责任者（文件形成者或第一责任者）、文件题名（无题名由立卷人拟写）、日期、**页数**、备注、档号。

> 注意：2008 版把 2000 版的"页号"改为"**页数**"（每件文件总页数）。

### 卷内备考表项目
档号、**互见号**（反映同一内容不同载体档案的档号，注明载体类型）、说明、**立卷人、立卷日期、检查人、检查日期**。

- 位置：排列在卷内**全部文件之后**，或直接印制在**卷盒内底面**。

### 案卷目录项目
序号、档号、案卷题名、保管期限、**总页数**、备注。

## 六、案卷装订（第 7 章）

- 可**整卷装订**或**以件为单位装订**；
- 以件装订的：在每件文件**首页空白处加盖档号章**（2008 版由"装订线上"改为首页空白处）；
- 超出卷盒幅面的科技文件应**折叠**（图纸折叠按 **GB/T 10609.3**）；破损文件修复。

## 七、卷盒、表格规格与制成材料（第 8 章）

| 项目 | 规格/材料 |
| --- | --- |
| 卷盒外表面 | **310mm×220mm**，脊背厚度 D=10/20/30/40/50/60mm |
| 卷盒材料 | **220g 以上单层无酸牛皮纸板双裱压制** |
| 表格（案卷目录、卷内目录、卷内备考表） | **297mm×210mm**，**70g 以上白色书写纸** |

## 八、必背数字速记

| 要点 | 内容 |
| --- | --- |
| 3 个原则 | 形成规律、有机联系、成套系统 |
| 2 个要求 | 齐全完整签章完备；载体材料符合保护要求 |
| 4 个排序口诀 | 文前图后；印前定后；正前附后；复前来后 |
| 科研 6 阶段 | 立项→论证→实验→鉴定→成果申报→应用 |
| 建设 7 阶段 | 前期→设计→施工→监理→竣工→验收→后评估 |
| 档号 3 要素 | 全宗号 + 分类号（项目代号/目录号）+ 案卷号 |
| 2 个不编页号 | 卷内目录、卷内备考表 |
| 卷盒 310×220 | 220g 无酸牛皮纸板双裱 |
| 表格 297×210 | 70g 以上白色书写纸 |
