# 06 电子印章管理办法（国办发〔2025〕33 号）

## 一、办法名片

| 项目 | 内容 |
| --- | --- |
| 文号 | 国办发〔2025〕33 号，2025-09-27 印发（成文），2025-10-09 发布 |
| 施行 | **自印发之日起施行** |
| 结构 | 8 章 38 条 |
| 制定依据 | 电子签名法、密码法、网络安全法、数据安全法及印章管理有关法律法规 |

## 二、基本概念与效力（第 1—5 条）

### 电子印章定义
基于**密码技术和相关数字技术**表征印章的**特定格式数据**，用于实现电子文件的**可靠电子签名**。

电子印章包含：①印章图像数据 ②印章名称 ③印章所有者信息 ④电子签名认证证书 ⑤与其关联的电子签名制作数据。

### 适用范围
单位（组织）的**法定名称章**、以法定名称冠名的**内设机构章、分支机构章、业务专用章**，以及用于单位（组织）事务办理的**个人名章**。

### 原则与效力
- 原则：**统筹推进、分级管理、规范标准、安全可控**。
- **电子印章与实物印章具有同等法律效力**；经电子签章的电子文件与加盖实物印章的纸质文件**同等效力**（法律、行政法规明确不适用的除外）。

## 三、管理和服务主体（第 6—12 条）——部门分工

| 主体 | 职责 |
| --- | --- |
| 国家密码管理局 | 电子印章密码管理；电子政务电子认证服务监管；标准化；促进政务活动互信互认；统筹协调推广应用 |
| 国务院办公厅 | 依托**全国一体化政务服务平台**推动政务服务、公共服务及相关社会化服务领域互信互认 |
| 工业和信息化部 | 电子印章相关的**电子认证服务**监督管理 |
| 公安机关 | 依法打击涉及电子印章的违法犯罪行为 |
| 省级密码管理部门 | 本行政区域密码管理、电子政务电子认证服务监管、标准化、互信互认 |
| 制发部门 | 各地区各部门参照印章管理法规明确，负责电子印章**申请和注销**管理 |
| 制作管理单位 | 负责电子印章**制作、备案**等工作 |

- 电子政务电子认证服务：由**依法设立的电子政务电子认证服务机构**提供；电子认证服务由依法设立的电子认证服务机构提供（第 12 条）。

## 四、制作、备案与注销（第 13—20 条）

### 制作材料四项（第 14 条）
1. 电子印章申请通过的相关证明材料；
2. 单位（组织）的设立批准文件或设立登记证件；
3. 制作电子印章的相关数据和信息；
4. 制作管理单位规定提交的其他材料。

> 鼓励通过**数据共享**方式获取材料；企业、社会组织申请程序可适当简化。

### 制作要求（第 16 条）
- 电子签名认证证书**合法有效**，由依法设立的认证机构签发；**电子印章有效期截止时间不超过证书有效期截止时间**；
- 数据格式、生成流程、应用接口符合国家标准规范；
- 图像规格、式样与**印模规制**保持一致，可附加标注字样；无对应实物印章的可参照相近实物印章印模规制。

### 备案与状态
- 制作完成后**备案**；停用、恢复等状态变更**及时备案**；提供**状态信息查询服务**。
- **重新制作情形**：有效期到期、载体损坏或遗失、电子签名制作数据失密。
- **注销情形**：更名、解散、撤销、被吊销、破产、分立、合并；应注销而未注销的由制发部门提出处理意见；也可主动注销。
- 制作、备案**操作记录和操作结果长期保存**；受托单位受制作管理单位监督。

## 五、使用管理（第 21—24 条）

- **使用原则（必背）**："**谁所有、谁控制，谁签章、谁负责**"。
- 电子签章要求：使用**有效**电子印章，保证电子签章数据的**真实性、完整性和不可否认性**；过程信息记录保存，实现**可追溯、可定责**。
- 验证：核验电子签章数据的真实性、完整性、不可否认性，并核验电子印章**在电子签章时的有效性**。
- **归档衔接**：经电子签章的电子文件归档时，应符合电子档案管理有关规定和标准规范（→ 呼应国家档案局令第 22 号"归档去除数字签名、只保留印章图形"）。

## 六、互信互认（第 25—27 条）

- 推动跨地区、跨部门互信互认支撑能力建设；**规范电子印章编码**；促进状态信息及认证证书链信息共享。
- 行政机关及履行社会管理和公共服务职能的企事业单位、社会组织：业务信息系统应**支持符合规定的电子印章接入使用**。
- 经电子签章的电子文件应实现**跨层级、跨地域、跨系统、跨部门、跨业务**互通互认（"五跨"）。

## 七、安全管理与责任（第 28—33 条）

- 信息保护制度：防止未经授权的访问及信息泄露、篡改、毁损、丢失；涉密信息系统按保密规定执行。
- 责任：
  - 受托制作单位违法违规制作/不履行安全义务 → 责令限期改正 + **标识为无效**；逾期不改正依法追责；
  - 认证服务违法影响印章有效性 → 相关电子印章**标识为无效**；
  - 伪造、变造、冒用、盗用电子印章 → 依法担责；
  - 监管人员失职渎职 → 依法追责，涉嫌犯罪移送。

## 八、附则与术语（第 34—38 条）

- **电子印章所有者**：对电子印章拥有所有权的单位（组织）或个人；电子签名制作数据归所有者**专有**。
- **电子签章**：使用电子印章签署电子文件的过程，结果数据为电子签章数据。
- 仅用于单位内部业务的电子印章：可参照本办法**自行组织制作和管理**。
- 行政机关以外的其他国家机关可参照；涉密领域有特别规定的从其规定。
