# 12 DA/T 63—2017 录音录像类电子档案元数据方案

## 一、标准名片

| 项目 | 内容 |
| --- | --- |
| 发布 | 2017 年（本文件为**报批稿**，格式为 XX/T XXXXX—XXXX） |
| 提出/归口 | 江西省档案局（馆）提出，国家档案局归口 |
| 起草 | 江西省档案局 |
| 适用 | 以**卷、件**为管理单元的录音、录像类电子档案；经数字化转换形成的录音录像档案数字副本管理**可参照执行** |
| 参照 | ISO 23081-2:2009；DA/T 54—2014（照片类电子档案元数据方案） |

## 二、基础概念（第 3 章）

- 录音类电子文件：经**数字录音设备**形成的数字音频文件（由内容、结构、背景组成）。
- 录像类电子文件：经**数字摄像设备**形成的数字音视频文件（由内容、结构、背景组成）。
- 电子档案 = 具有**查考和利用价值**并归档保存的电子文件。

## 三、四类元数据实体（第 4 章）——与 DA/T 46 不同（必背）

| 实体 | 英文 | 描述 |
| --- | --- | --- |
| ① 档案实体 | record entity | 任一聚合层次的电子档案 |
| ② 业务实体 | business entity | 电子档案得以形成的**职能业务活动** + 归档、移交、转换、迁移、处置等**管理活动** |
| ③ 机构人员实体 | agent entity | 负责实施电子档案管理活动的个人或组织 |
| ④ 授权实体 | mandate entity | 实施管理活动的授权（法律法规、政策、标准与业务规则等） |

### 实体约束性
- **档案实体：必选**；
- 可采用**单实体方案**（仅含档案实体）或**多实体方案**；
- 多实体方案：档案、业务、机构人员实体**必选**，授权实体**可选**；**推荐多实体方案**。

> 对比记忆：DA/T 46 的四个"域"是文件实体、机构人员实体、业务实体、实体关系；DA/T 63 的四个"实体"是档案实体、业务实体、机构人员实体、授权实体。

## 四、档案实体元数据（M1～M75）——分组速记

约束符号：M 必选、C 条件选、O 可选、R 可重复、NR 不可重复。

### 1. 标识与聚合（M1～M6）
| 编号 | 元数据 | 说明 |
| --- | --- | --- |
| M1 | 档案馆代码 | O,NR |
| M2 | 统一社会信用代码 | O,NR（GB 32100） |
| M3 | 档案门类代码 | O,NR |
| M4 | 聚合层次 | **M**,NR |
| M5 | 唯一标识符 | O,NR；推荐两种规则：档案馆代码+"·"+档号；或 国家代码+档案馆代码+全宗号+档案门类代码+形成年度+顺序号 |
| M6 | 档号 | **M**,NR，按 DA/T 13 编制 |

### 2. 责任与著录（M7～M12）
M7 题名(M)、M8 责任者(M)、M9 **摄录者**(M)、M10 编辑者、M11 著录者、M12 数字化责任信息。

### 3. 时间与时长（M13～M18）
M13 时间(M)、M14 **摄录时间**(M)、M15 编辑时间、M16 数字化时间、M17 **时间长度**(M)、M18 总帧数。

### 4. 内容描述（M19～M22）
M19 主题(R)、M20 内容描述、M21 内容起始时间、M22 内容结束时间。

### 5. 来源（M23～M26）
M23 来源、M24 获取方式、M25 来源名称、M26 源文件标识符。

### 6. 权限与保管（M27～M32）
M27 **保管期限**(M)、M28 **权限**(M)、M29 **密级**(M)、M30 控制标识、M31 版权信息、M32 附注。

### 7. 存储与载体（M33～M38）
M33 存储、M34 在线存址、M35 离线存址、M36 原始载体、M37 原始载体类型、M38 原始载体型号。

### 8. 生成与设备（M39～M45）
M39 **生成方式**(M)、M40 **捕获设备**(M,R)（子：M41 设备类型、M42 **设备制造商**(M)、M43 **设备型号**(M)）、M44 软件信息、M45 信息系统描述(R)。

### 9. 文件与格式（M46～M51）
M46 **计算机文件名**(M)、M47 **计算机文件大小**(M,R)、M48 **格式信息**(M,R)（子：M49 格式名称、M50 格式版本、M51 格式描述）。

### 10. 音视频技术参数（M52～M66）
- **视频参数** M52(R)：M53 视频编码标准、M54 色彩空间、M55 分辨率、M56 帧率、M57 视频比特率、M58 色度采样率、M59 视频量化位数、M60 画面高宽比；
- **音频参数** M61(R)：M62 音频编码标准、M63 音频比特率、M64 音频采样率、M65 音频量化位数、M66 声道。

### 11. 数字签名与参见（M67～M75）
M67 参见号、M68 **数字签名**(R)（子：M69 签名格式描述、M70 签名时间、M71 签名者、M72 签名、M73 证书、M74 证书引证、M75 签名算法）。

## 五、业务实体（M76～M87）——按 DA/T 54—2014 描述

M76 职能业务、M77 业务类型、M78 业务名称、M79 业务开始时间、M80 业务结束时间、M81 业务描述、M82 **管理活动**(C,R)（子：M83 管理活动标识符、M84 管理行为、M85 管理时间、M86 管理活动描述）、M87 关联实体标识符。

> 业务实体 = 职能业务（形成活动）+ 管理活动（归档、移交、转换、迁移、处置）。

## 六、机构人员实体（M88～M92）

M88 机构人员标识符、M89 机构人员名称、M90 机构人员类型、M91 机构人员代码、M92 机构人员隶属。

## 七、授权实体（M93～M96）

M93 授权标识符、M94 授权名称、M95 授权类型、M96 发布时间。

## 八、必选元素清单（档案实体）

**必选（M,NR）**：M4 聚合层次、M6 档号、M7 题名、M8 责任者、M9 摄录者、M13 时间、M14 摄录时间、M17 时间长度、M27 保管期限、M28 权限、M29 密级、M39 生成方式、M42 设备制造商、M43 设备型号、M46 计算机文件名。

**必选可重复（M,R）**：M40 捕获设备、M47 计算机文件大小、M48 格式信息。

> 记忆：声像档案必选核心 = 档号题名责任者、摄录者摄录时间长度、保管权限密级、生成方式设备、文件名大小格式。

## 九、与 DA/T 46 的异同（对比记忆）

| 维度 | DA/T 46—2009（文书类） | DA/T 63—2017（录音录像类） |
| --- | --- | --- |
| 四个域/实体 | 文件、机构人员、业务、实体关系 | 档案、业务、机构人员、授权 |
| 元素总数 | M1～M88 | M1～M96 |
| 特色元素 | 聚合层次、档号、电子属性、数字化属性、电子签名 | 摄录者、摄录时间、时间长度、总帧数、视频/音频参数、捕获设备、原始载体 |
| 数字签名 | 电子签名（M57） | 数字签名（M68） |
| 描述方法 | 编号/名称/定义/目的/约束/重复/类型/数据类型/编码/值域/缺省/子元素/来源/相关/注释 | 同左 + **适用门类**（录音/录像） |
| 参照 | ISO 23081 | ISO 23081、DA/T 54—2014 |
