# 05 电子档案管理办法（国家档案局令第 22 号）

## 一、办法名片

| 项目 | 内容 |
| --- | --- |
| 公布 | 2024-09-14 国家档案局令第 22 号 |
| 施行 | **2024-11-01** |
| 结构 | 7 章 38 条 |
| 适用范围 | 档案馆和机关、团体、企业事业单位及其他组织的电子档案管理 |

## 二、核心概念与总则（第 1—8 条）

### 电子档案定义
机关、团体、企业事业单位和其他组织以及个人在**履行法定职责或者处理事务过程中**，通过计算机等电子设备**形成、办理、传输、存储**的，对国家和社会具有**保存价值并归档保存**的各种**信息记录**。

### 电子档案三要求（第 3 条，必背）
| 要求 | 含义 |
| --- | --- |
| 来源可靠 | 合法、明确的形成者，法定职责/事务中产生；形成者、形成活动、形成时间可确认；形成、办理、整理、归档、保管、移交等系统安全可靠 |
| 程序规范 | 全过程管理符合法律法规和标准规范，准确记录、**可追溯** |
| 要素合规 | 内容、结构、背景信息和管理过程信息等构成要素符合标准规范 |

- 电子档案与传统载体档案**同等效力**，可以电子形式作为凭证使用。
- 全过程管理：形成、整理、归档、移交、接收、保管、处置、利用各环节应用系统**相互衔接**，持续进行**元数据采集、维护**。
- 目标：电子文件**应归尽归**、电子档案**应收尽收**。
- 底线：全过程符合**网络安全、数据安全、个人信息保护、保密管理、密码管理**等法律法规要求。

## 三、机构职责（第 9—13 条）

- 国家档案局：统筹规划、组织协调、监督指导，建标准规范体系，推进**全过程管理能力评估**。
- 乡镇人民政府：将电子档案管理**纳入档案工作范围**，监督指导所属企事业单位、基层群众性自治组织。
- 单位职责：纳入档案工作责任制和信息化建设规划；协调**档案、文秘、业务、信息化、保密**等职能部门；形成部门负责本部门收集整理归档；管理机构负责管理并监督指导、按规定移交。
- 档案馆：建设长期保存和安全管理的**信息化基础设施**，收集保管提供利用，建制度规范。

## 四、电子文件整理与归档（第 14—19 条）

- 归档范围、保管期限、分类方案：纳入本单位文件材料归档范围和档案保管期限表、档案分类方案**统一管理**。
- 归档功能：办公自动化系统、业务系统归档功能符合标准规范。
- **电子文件与元数据一并归档**。
- **归档格式五特性**：开放、不绑定软硬件、**显示一致性**、可转换、易于利用，且能支持向**长期保存格式**转换。
- **禁止采用非开放的压缩、加密等技术措施归档**（第 17 条）。
- **电子印章处理（高频考点）**：党政机关电子公文归档，应当**去除电子印章的数字签名信息，只保留印章图形**；其他组织可参照。
- 归档前：清点、登记、检测"四性"（真实性、完整性、可用性、安全性），由**相关责任人确认**。
- 归档后：审核、**编制档号**、确认保管期限。

## 五、电子档案移交与接收（第 20—23 条）

- 定期移交；符合要求的**不得拒绝接收**。
- 专业性强或需保密的：经同级档案主管部门同意可**延长移交期限**。
- 未到移交期限的：经档案馆同意，明确移交期限届满前的**利用、转换、迁移等权责**后可提前交档案馆保管。
- **移交四项要求（第 21 条）**：
  1. 按移交接收标准规范组织，四性检测合格后方可移交；
  2. **不保留电子印章数字签名信息，只保留印章图形**；
  3. 采用技术手段加密的**去除加密措施后移交**；
  4. 附具**到期开放意见、政府信息公开情况、密级变更情况**等。
- 移交方式：符合安全管理要求的**网络和信息系统**在线移交；不具备条件的用符合安全要求的**存储介质离线移交**。

## 六、电子档案保管与处置（第 24—30 条）

### 备份（第 26 条，必背数字）
- 在**磁介质、光介质、缩微胶片**中选择**至少两种**符合长期安全管理要求的介质；
- 以**在线 + 离线**方式保存**至少三套**完整数据，**每种介质上一套**；
- 分工：**一套在线应用，两套备份**；
- 制定检测策略，定期检测可读状况、软硬件环境、介质完好程度，必要时转换、迁移。

### 异地备份与灾备（第 27 条）
- 档案馆对**重要电子档案异地备份**；有条件建灾难备份系统；国家档案馆可建设**电子档案备份中心**。

### 转换迁移（第 28 条）
- 经**技术需求分析、风险评估**，确有必要的才转换、迁移；**留存操作过程记录**；迁移后进行四性检测。

### 鉴定与销毁（第 29—30 条）
- 定期鉴定到期档案；仍需保存的重划保管期限并**变更相关管理数据**。
- 销毁：履行审批手续，**禁止擅自销毁**；从**在线存储设备、容灾备份系统和离线存储介质中彻底删除**，并记录被销毁档案的**范围、数量、大小以及审核人、操作者**等信息。

## 七、开放与利用（第 31—36 条）

- 定期公布开放电子档案目录；利用不得擅自复制、篡改。
- 按服务对象和利用范围建立**相应网络**的档案数字资源利用服务平台（政务网、互联网等）。
- 积极利用**人工智能**开展编研、展览、专题数据库建设。
- 促进档案数字资源**跨区域、跨层级、跨部门**共享利用。

## 八、必背数字速记

| 数字/要点 | 内容 |
| --- | --- |
| 三要求 | 来源可靠、程序规范、要素合规 |
| 五特性 | 开放、不绑定软硬件、显示一致性、可转换、易于利用 |
| 二介质 | 磁/光/缩微胶片中至少选两种 |
| 三套数据 | 在线+离线至少三套；每种介质一套；一套在线应用、两套备份 |
| 一个动作 | 归档/移交均去除电子印章数字签名，只保留印章图形 |
