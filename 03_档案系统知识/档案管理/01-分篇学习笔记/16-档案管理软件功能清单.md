# 16 档案管理软件功能清单（需求清单）

## 一、文档定位

这是一份企业级**档案管理软件功能需求清单**（共 25 项），覆盖从个人使用到系统管理的完整功能链，可作为系统选型、需求分析、功能验收的检查表。学习时按"**子系统—功能—要点**"分层记忆。

## 二、核心子系统（6 大块）

### 1. 个人中心
我的首页、我的收藏、我的申请、我的办理（我的待办、我的已办、访问历史、消息提醒、暂存架、用户反馈）。

### 2. 安全管理子系统（安全"三件套"）
| 功能 | 要点 |
| --- | --- |
| 原文校验 | 每份电子文件赋予**唯一 MD5 码**，实现唯一值追溯 |
| 水印设置 | 静态水印、动态水印、图片水印；**防拍屏** |
| 安全设置 | **三级安全设置模式** |

### 3. 收集整理子系统（入口）
文件收集（条目增删改、导入导出、原文管理、批量挂接）、文件整理（整理标引、立卷整理、档号整理、档案装盒、综合排序、报表管理、数据回收站）、归档/进馆申请、导入数据接口（条目导入、合规校验）、数据审核（检索、查看原文、接收数据）。

### 4. 档案管理子系统（核心）
- 档案管理：条目/原文管理、整理标引、立卷整理、档号整理、装盒、数据计算、日志查看；
- **档案统计**：常规统计（归档率、馆/室藏、借阅、销毁）+ 图表（柱状、饼状、折线）；精准统计（按年度、保管期限统计盒数、件数、页数、电子文件大小）；
- 档案销毁：销毁库管理、销毁流程管理；
- 利用台账：电子借阅、实体借阅台账；
- 检索：模糊检索（结果中二次检索）、高级检索（跨字段精确）；
- 批量操作：类电子表格批量修改（按内容/位置替换、合并著录项、序号自生成、加前后缀）、批量删除。

### 5. 利用子系统（出口）
- 档案检索：条目检索（目录/高级）+ **全文检索**（双层 PDF、Word、表格、PPT 等矢量文件）；
- 文件在线阅读：免插件，支持 **mp3、wav、mp4、flv** 等声像在线播放；
- 档案利用：电子借阅、实体借阅、协查流程申请/审批；
- 档案编研：编研大纲、模板设计、主题内容筛选在线编辑；
- 借阅登记与归还登记（含续借）。

### 6. 工作协同子系统
- **工作流定制**：图形化定制，支持电子借阅/实体借阅/档案协查/档案鉴定流程，流程节点和变量定义；
- 工作流监控：图形化跟踪、自动播放进度、强制终止、调整节点人员。

### 7. 系统管理（SYS）
组织机构、用户、角色、全宗管理、同义词库、菜单、系统字段、参数、管理员、服务监控、定时任务、系统日志、档案库管理、档案模板管理、档案分类管理、词典管理等。

## 四、学习记忆要点

1. **流程主线**：收集整理（进）→ 档案管理（管）→ 利用服务（用）→ 统计/销毁（控）。
2. **安全四层**：MD5 校验 + 水印防拍 + 三级安全模式 + 四性检测。
3. **"智能"家族 6 项**：智能打码、智能档号章、智能质检、OCR 在线录入、PDF 拆分、大数据展示。
4. **对接集成 4 项**：单点登录、OA 接口、库房系统对接、数据迁移。
5. **检索三层**：模糊检索 → 高级检索（跨字段）→ 全文检索（内容级）。
6. **借阅闭环**：申请/审批 → 借阅登记 → 归还/续借 → 到期提醒 → 利用台账。
