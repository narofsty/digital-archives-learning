# 15 DA/T 78—2019 录音录像档案管理规范

## 一、标准名片

| 项目 | 内容 |
| --- | --- |
| 发布/实施 | 2019-12-16 发布，**2020-05-01 实施** |
| 归口 | 国家档案局提出并归口（起草含江西省档案馆） |
| 内容 | 模拟信号录音录像文件和录音录像电子文件的**收集、整理、著录、归档**与录音录像档案管理要求 |

## 二、核心术语（第 3 章）

- 录音录像文件：履行法定职责过程中采用**不同记录载体**形成的以声音或影像为主要呈现方式的信息记录。
- 录音录像电子文件：通过计算机、数字化转换等电子设备形成的数字音频和数字音视频文件（由内容、结构、背景组成）。
- **件（自然件）**：由摄录设备**连续录制或拍摄形成**并独立存在的录音录像文件。
- 原始载体：可追溯到的最早的记录载体和离线归档载体（录音带、录像带、DVD-R、BD-R、移动硬盘等）。
- 离线备份载体：以备份为目的、脱离计算机和网络保存的可移动存储介质。

## 三、总则（第 4 章）

- **基本原则**：集中管理、过程管理、便于利用、安全保密；确保四性（真实、完整、可用、安全）。
- 部门职责（四部门，与 GB/T 18894 一致）：形成部门（收集整理著录归档）、档案部门（制度、指导、接收、保存保管利用统计移交）、信息化部门（技术支撑）、保密部门（监督涉密）。

## 四、收集（第 5 章）——格式要求是重点

### 收集范围（4 类）
1. 记录本单位主要职能和基本历史面貌的（工作活动、重要会议、外事活动、重点工程、重要人物；重大活动；上级领导著名人物视察调研；重大自然灾害、重大事故、突发事件）；
2. 记录本地区地理概貌、城乡建设、名胜古迹、自然风光、民风民俗和人物宣传的；
3. 执法部门或司法部门职能活动形成的；
4. 其他具有保存价值的。

### 收集要求
- 录像电子文件应是**音频、视频封装为一体**的音视频文件；
- 多件反映相同场景的：挑选**影像清晰、人物端正、声音清楚、画面构图平衡**的一件归档；
- 重大活动筹备实施中的文字材料、实物（公文、日程、讲话、名册、签名册、座次表、宣传册、活动标志、印章、证件、礼品、纪念章、场馆设计图等）**一并收集归档**。

### 归档格式（必背）
| 类型 | 归档格式 | 技术要求 |
| --- | --- | --- |
| 录音 | WAV、MP3、AAC 等 | 音频采样率**不低于 44.1kHz** |
| 录像 | MPG、MP4、FLV、AVI 等 | 视频比特率**不低于 8Mbps**；珍贵的可另归档一套 **MXF** |

## 五、整理与著录（第 6 章）

- 以**件**为管理单位整理；保持内在有机联系，建立文件与目录数据**一一对应**关系。
- 保管期限：**永久、定期 30 年、定期 10 年**。
- 分类方法：**年度—保管期限** 或 **保管期限—年度**。
- 存储：按分类类目（年度、保管期限）**逐级建立、命名文件夹**。
- 著录依据 **DA/T 63—2017**；可使用 **ET、XLS** 通用电子表格。

### 基本著录项（16 项，全部必选——记忆）
计算机文件名、题名、责任者、摄录者、摄录日期（yyyy-mm-dd 或 yyyymmdd）、时间长度（hh:mm:ss）、计算机文件大小、年度、工作活动名称、工作活动描述、**保管期限代码（Y/D30/D10）**、密级（秘密/机密/绝密）、原始载体编号、**档案门类代码（录音 LY、录像 LX）**、参见号、著录者。

> 与 DA/T 63 映射举例：题名↔M7、责任者↔M8、摄录者↔M9、摄录日期↔M14、时间长度↔M17、计算机文件大小↔M47、工作活动名称↔M78 业务名称、工作活动描述↔M81 业务描述、密级↔M29、参见号↔M67、著录者↔M11。

## 六、归档与管理（第 7 章）

### 归档时间（必背）
- 自录音录像文件形成起 **3 个月内**向档案部门提交归档；
- **最迟不能超过形成后的次年 6 月**。

### 归档方式与程序
- 在线归档（基于电子档案管理系统）或离线归档（原始载体）；
- 程序按 GB/T 18894 8.1：**清点、鉴定、登记、填写《录音录像文件归档登记表》**；
- 清点内容：文件与原始载体数量一致性、载体完好、重大活动文字材料实物数量；检测格式著录规范性、病毒。

### 档号编制两种规则（必背）
1. **全宗号-档案门类代码·年度-保管期限代码-件号**；
2. **全宗号-档案门类代码·保管期限代码-年度-件号**。

> 编档号后由系统**自动用档号重命名**电子档案并更新计算机文件名元数据。

### 保存与保管
- 在线存储 + 近线备份 + 离线备份（按 GB/T 18894、DA/T 38、DA/T 74、DA/T 75）。
- **转换迁移时机**：在线存储系统更新换代、离线备份载体达**三级预警线**、存储格式即将淘汰。
- 载体保管（数字考点）：
  - 防写处理；装盒、**竖立存放**、避免挤压；远离强磁场强热源、与有害气体隔离；
  - 温度：光盘 **17℃～20℃**，磁性载体 **15℃～27℃**；24h 内温度变化分别**不超过 ±2℃、±3℃**；
  - 湿度：光盘 **20%～50%**，磁性载体 **40%～60%**；24h 内湿度变化**不超过 ±5%**。
- 检测：光盘参数超三级预警线、硬磁盘异常 → **立即**转换或更新，建立管理台账并归档。

### 利用、统计、移交
- 利用在权限范围内，未经授权**不得擅自复制**；人物影像、版权保护期内的利用符合国家规定。
- 移交：符合要求的录音录像电子档案自形成之日起 **5 年内**向同级国家综合档案馆移交。

## 七、必背数字速记

| 要点 | 内容 |
| --- | --- |
| 2 个格式指标 | 音频采样率 ≥44.1kHz；视频比特率 ≥8Mbps |
| 3 个月 | 形成起 3 个月内提交归档 |
| 次年 6 月 | 归档最迟时限 |
| 5 年 | 向国家综合档案馆移交期限 |
| 16 项 | 基本著录项（全部必选） |
| 2 种档号规则 | 全宗号-门类·年度-期限-件号；全宗号-门类·期限-年度-件号 |
| 2 个门类代码 | 录音 LY、录像 LX |
| 3 个期限代码 | Y、D30、D10 |
| 温湿度 | 光盘 17～20℃/20%～50%；磁性 15～27℃/40%～60% |
| 4 个部门 | 形成、档案、信息化、保密 |
