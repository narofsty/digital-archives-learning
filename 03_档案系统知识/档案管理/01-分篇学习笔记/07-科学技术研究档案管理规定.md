# 07 科学技术研究档案管理规定（国家档案局令第 15 号）

## 一、规定名片

| 项目 | 内容 |
| --- | --- |
| 公布 | 2020-09-11 国家档案局令第 15 号 |
| 施行 | **2020-11-01**（同时废止 1987 年《科学技术研究档案管理暂行规定》） |
| 解释 | 国家档案局、科学技术部 |
| 结构 | 28 条（不分章） |
| 依据 | 档案法、《科学技术档案工作条例》及国家科技管理有关法律法规 |

## 二、总则要点（第 1—9 条）

### 科研档案定义
科研项目在**立项论证、研究实施及过程管理、结题验收及绩效评价、成果管理**等过程中形成的，具有保存价值的文字、图表、数据、图像、音频、视频等各种形式和载体的**文件材料**以及**标本、样本等实物**。

> 注意：科研档案不仅包括文件材料，还包括实物（标本、样本）。

- 工作定位：科研管理的重要组成部分、科研活动的重要环节；与科研项目工作**同部署、同实施、同检查**，列入职责并**考核**。
- 结题验收：按**分类分级管理**原则，对科研档案的**完整性、准确性、系统性**审查或验收（"三性"）。
- 管理原则：**集中统一管理**；确保科研档案**完整、准确、可用、安全**。
- 任何人不得以任何理由将应当归档的科研文件材料**据为己有或拒绝归档**。
- 经费：科研档案工作经费纳入本单位预算；支出列入**科研项目预算相关科目**。

## 三、职责体系（第 8—13 条）

| 主体 | 职责 |
| --- | --- |
| 国家档案主管部门 | 全国科研档案工作监督指导 |
| 国家科技主管部门 | 在国家科技计划组织实施中加强统筹协调 |
| 上级主管部门（机构） | 纳入本系统整体工作范畴 |
| 地方科技主管部门（机构） | 会同档案主管部门对本区域科研档案监督指导 |
| 中央财政支持的科研项目管理单位 | 对所负责项目档案工作负责，制定制度、建立机制 |
| 科研项目承担单位（含牵头） | 对所承担项目档案工作**负总责**，对参加单位提要求、明确档案归属与流向 |
| 项目负责人 | 对归档科研文件材料的**完整性、准确性、系统性负责** |
| 专人 | 负责科研文件材料的收集、整理、审核，结题验收后**及时归档** |
| 单位档案部门 | 集中统一管理，监督指导归档，协助收集整理和结题验收 |

## 四、归档范围（第 14 条）——四阶段记忆

| 阶段 | 主要内容 |
| --- | --- |
| ① 立项论证 | 项目指南、可行性研究报告、经费预算、申报书、立项评审、立项批复、任务合同书（含预算书）、各类协议 |
| ② 研究实施及过程管理 | 研究计划、任务书/大纲；实验/探测/测试/观测/野外调查等的**原始记录**；设计文件图样、集成电路布图、工艺文件、计算文件、数据处理文件、**科学数据**；样机样品标本实物及目录；阶段进展报告、调整变更材料、撤销项目材料；专家咨询、中期检查评审、项目监督材料；中试线、试验基地、示范点材料 |
| ③ 结题验收及绩效评价 | 验收申请书、承诺书；工作总结/技术报告、经费决算；验收通知、评审材料、现场测试报告、第三方检测评估报告、用户报告；验收结论书；绩效自评价报告、专家评议、评价结论 |
| ④ 成果管理 | 研究报告、论文、专著、数据库；自评价报告、科技报告；专利、软件及其他知识产权材料；产业化报告、证书、出版物、获奖宣传材料 |

## 五、归档与电子化要求（第 15—19 条）

- 归档三要求：
  1. 制成材料符合国家规范；
  2. 项目完成或中止后系统整理、履行审查手续后**及时归档**；周期长的项目**可分阶段归档**；
  3. 按项目性质、规模、创新性确定保管期限：**永久和定期，定期一般分 30 年、10 年**。
- 科研电子文件：按国家电子文件归档和电子档案管理规定执行；项目管理系统应设置**归档功能或接口**。

### 仅以电子形式归档的六条件（第 18 条，重点）
1. 电子文件**来源真实有效**，由计算机等电子设备形成和传输；
2. 形成系统能准确、完整、有效接收读取，能输出符合国家标准归档格式的文件，设定了**经办、审核、审批**等审签程序；
3. 电子档案管理系统能有效接收、管理、利用，功能符合**长期保管**要求；
4. 采取有效措施**防止被篡改**；
5. 建立**备份制度**，防范自然灾害、意外事故和人为破坏；
6. 外部接收的电子文件**来源可靠、程序规范、要素合规**。

- 整理标准：纸质科研档案按 **GB/T 11822**（科技档案案卷构成）；科研电子档案按 **GB/T 18894**（电子文件归档与电子档案管理）。有条件可数字化。

## 六、保管、鉴定、利用与协作（第 20—27 条）

- 保管：库容量满足未来增长需要；定期检查、及时修复破损；涉密按国家规定。
- 鉴定：档案部门牵头，组织有关部门或人员共同进行；需继续保存的重划期限；确无保存价值的按国家规定销毁。
- 利用：建立开放利用机制，促进信息共享；符合**知识产权保护**要求；涉密遵守保密规定。
- 统计：建立统计制度。
- **分工合作项目（第 24 条）**：
  - 以任务合同或分工协议**书面明确**档案归属、流向、处置和利用共享；
  - 一般由**牵头承担单位保存一套完整档案**；
  - 参加单位保存本单位承担任务形成的档案，并**将副本或复制件送交牵头承担单位**；
  - 涉及参加单位或科研人员合法权益不宜送交副本且有书面约定的，参加单位应将**档案目录**送交牵头承担单位。
- 计划管理单位及项目综合管理形成的档案可按**文书档案**管理。

## 七、速记要点

| 记忆点 | 内容 |
| --- | --- |
| 一个定义 | 科研档案 = 文件材料 + 实物（标本、样本） |
| 四个阶段 | 立项论证 → 研究实施及过程管理 → 结题验收及绩效评价 → 成果管理 |
| 三性审查 | 完整性、准确性、系统性 |
| 四性保障 | 完整、准确、可用、安全 |
| 期限两档 | 定期 30 年、10 年（另有永久） |
| 六条件 | 纯电子归档的六个前置条件 |
| 牵头单位 | 保存一套完整档案；参加单位送副本（或目录） |
| 两个标准 | GB/T 11822（纸质）、GB/T 18894（电子） |
