# 08 GB/T 18894—2016 电子文件归档与电子档案管理规范

## 一、标准名片

| 项目 | 内容 |
| --- | --- |
| 发布/实施 | 2016-08-29 发布，**2017-03-01 实施** |
| 代替 | GB/T 18894—2002《电子文件归档与管理规范》 |
| 归口 | 国家档案局提出并归口 |
| 定位 | 电子文件归档与电子档案管理的**基础性国家标准** |
| 适用范围 | 机关、团体、企事业单位和其他组织在**处理公务过程中**产生的电子文件归档与电子档案管理 |

## 二、核心术语（第 3 章，必背定义）

| 术语 | 定义要点 |
| --- | --- |
| 电子文件 | 法定职责或处理事务过程中通过计算机等电子设备形成、办理、传输和存储的**数字格式信息记录**；由**内容、结构、背景**组成 |
| 电子档案 | 具有**凭证、查考和保存价值**并归档保存的电子文件 |
| 元数据 | 描述电子文件和电子档案的**内容、背景及其管理过程**的数据 |
| 组件 | 构成电子文件、电子档案且独立存在的一个**比特流**（如公文处理单） |
| 真实性 | 内容、逻辑结构和形成背景与**形成时原始状况相一致** |
| 可靠性 | 内容**完全和正确**地表达其所反映的事务、活动或事实 |
| 完整性 | 内容、结构和背景信息**齐全且没有破坏、变异或丢失** |
| 可用性 | 可以被**检索、呈现或理解** |
| 业务系统 | 形成或管理机构活动数据的计算机信息系统（OA、财务、人力资源、网站等） |
| 电子档案管理系统 | 对电子档案进行采集、归档、编目、管理和处置的计算机信息系统 |
| 采集/归档/移交/登记 | 收集存储过程 / 向档案部门提交管理权限 / 向国家档案馆移交保管权 / 进入系统时赋予**唯一标识符** |
| 转换/迁移 | 载体或格式转换 / 从一个系统转移到另一个系统（均须维护真实、完整、可用） |

## 三、总则与职责分工（第 4 章）

- 四项原则：纳入单位**信息化建设规划**、**技术与管理并重**、便于利用、安全可靠。
- 全程集中管理，确保**真实性、可靠性、完整性、可用性**（四性）。
- **四类部门分工（记忆）**：
  | 部门 | 职责 |
  | --- | --- |
  | 档案部门 | 定制度、提归档功能要求、系统建设与培训、指导归档、负责编目管理和处置 |
  | 形成/办理部门 | 收集、整理、著录、移交归档 |
  | 信息化部门 | 建设归档功能、参与系统建设、信息化支持 |
  | 保密部门 | 监督涉密电子文件归档和电子档案保密管理 |

## 四、系统功能要求（第 5 章）

- 业务系统归档功能要点：内置**分类方案、保管期限表**；以单个流式文档记录**全部修改信息**；自动命名、存储；按标准生成**归档数据包**或推送归档接口；对操作**跟踪、审计**。
- 电子档案管理系统功能五大类：
  1. **配置功能**：分类方案管理、档号规则管理、保管期限表管理、元数据方案管理、门类定义；
  2. **管理功能**：采集、登记、分类、编目、命名、存储、利用、统计、鉴定、销毁、移交、备份、报表管理；
  3. **安全管理**：身份认证、权限管理、跟踪审计、**生成固化信息**；
  4. **系统管理**：参数、用户和资源、功能配置、操作权限分配、事件报告；
  5. 纸质档案管理功能 + 数字化/数字副本管理功能。
- 网络安全：支撑系统运行的网络应与互联网**物理隔离**；与互联网设备之间的数据传输通过**一次性写入光盘**实施。

## 五、归档范围（第 6 章）

- 各门类电子文件及其元数据**一并收集、归档**。
- 文书类元数据**至少包括**（第 6.2.2）：
  - **文件实体元数据**：题名、文件编号、责任者、日期、机构或问题、保管期限、密级、格式信息、计算机文件名、计算机文件大小、文档创建程序；
  - **业务行为元数据**：发文（起草、审核、签发、复核、登记、用印、核发），收文（签收、登记、初审、承办、传阅、催办、答复），含行为时间、机构人员名称。
- 声像类元数据：题名、摄影者、录音者、摄像者、人物、地点、业务活动描述、密级、计算机文件名等。

## 六、收集与整理（第 7 章）

- 收集 6 方面要求：同一业务活动齐全完整；公文正本/正文与附件/定稿或修改稿/处理单齐全（格式符合 GB/T 9704）；CAD 产品模型图等齐全；声像客观完整反映内容人物场景；邮件网页社交媒体的文字图像动画音视频齐全、**网页版面格式保持不变**；专有格式不能转换时**同时收集专用软件、技术资料、操作手册**。
- 整理：以**件**为管理单位（也可按卷）；保管期限分**永久、定期 30 年、定期 10 年**。
- 声像类分类方案：**年度—保管期限—业务活动**或**保管期限—年度—业务活动**。

## 七、归档与编目（第 8 章）——重点

- 归档程序：**清点、鉴定、登记、填写归档登记表**；鉴定合格率应达到 **100%**。
- **归档时间**：最迟不能超过电子文件形成后的**第 2 年 6 月**。
- 归档方式：在线归档或离线归档（安全网络/专用离线存储介质）。
- **三种归档接口**：① WebService 接口 ② 中间数据库接口 ③ 归档电子文件及其元数据的规范存储结构。
- 归档格式五特性：**格式开放、不绑定软硬件、显示一致性、可转换、易于利用**，支持向长期保存格式转换。

### 分门类归档格式（记忆表）
| 门类 | 归档格式 |
| --- | --- |
| 版式文件 | 按 DA/T 47，可采用 **PDF、PDF/A** |
| 文书类正本/定稿/处理单 | **版式文件格式**；其他可用 RTF、WPS、DOCX、JPG、TIF、PNG |
| 科技类二维矢量 | SVG、SWF、WMF、EMF、EPS、DXF |
| 科技类三维矢量 | 需永久保存的转换 **STEP** 格式 |
| 数据库文件 | ET、XLS、DBF、XML 或转版式文件 |
| 照片 | JPG、TIF |
| 录音 | WAV、MP3 |
| 录像 | MPG、MP4、FLV、AVI；珍贵且需永久保存可加归档 **MXF** |
| 公务电子邮件 | EML |
| 网页、社交媒体 | HTML 等 |

- 编目：电子档案与纸质档案**同步整理审核、编制档号**；档号按 **DA/T 13**，能**唯一标识全宗内任一档案**；用文件级档号或唯一标识符重命名组件。

## 八、电子档案管理（第 9 章）

### 存储
- 在线存储设备 + 逐级文件夹 + 记录在线存储路径；在线存储系统实施**容错技术方案**，定期扫描诊断硬磁盘。

### 备份（数字考点）
- **近线备份**：宜采用**磁带备份系统**，定期全量、增量或差异备份。
- **灾难备份**：参照 **GB/T 20988**；数量大、条件许可可做**热备份**。
- **离线备份**：
  - 介质：**一次写光盘、磁带、硬磁盘**；
  - **至少制作一套**，可做第二套、第三套，装具上标识套别；
  - **光盘表面禁止粘贴标签**；防写处理、装盒竖立/平放、远离强磁场强热源有害气体；
  - **温湿度（必背）**：光盘 **17℃～20℃、相对湿度 20%～50%**；磁性载体 **15℃～27℃、相对湿度 40%～60%**；
  - 自形成起**一年内**可送同级国家综合档案馆电子档案中心备份；
  - 磁性载体**抽样检测率不低于 10%**，发现永久性误差扩大抽检或 100% 检测；
  - 光盘检测超**三级预警线**立即更新；技术淘汰立即转换介质；确认复制更新转换成功后对原介质**破坏性销毁**。

### 利用与统计
- 按岗位职责设置利用权限；**离线存储介质不得外借**，使用在档案部门监控范围内。
- 统计要素：门类、年度、保管期限、密级、卷数、件数、大小、格式、时长、销毁、移交等。

### 元数据维护
- 全程持续采集、备份、转换、迁移；
- **禁止修改背景、结构和管理过程元数据**；题名、责任者、文件编号、日期、人物、保管期限、密级等修改应符合管理规定并**记入日志**。

## 九、电子档案处置（第 10 章）

- 鉴定与审查：定期进行**销毁鉴定**和**解密审查**（档案部门+保密部门），意见经上级领导或主管部门审核批准后实施；**到期档案移交进馆前应进行解密审查**。
- **转换迁移八步骤（必背）**：确认需求→评估风险→制定方案→**审批方案**→转换迁移测试→实施→评估结果→报告结果。
- 转换迁移后：重新备份；活动记录于管理过程元数据，并填写登记表。
- 销毁：
  - 从**在线存储设备、异地容灾备份系统**中彻底删除；
  - 元数据移入**销毁数据库**，管理过程元数据、日志自动记录；
  - 离线介质**破坏性销毁**（销毁前先转换备份其他档案）；
  - 涉密档案按国家保密规定；填写**销毁登记表**并归档保存。
- 移交：按《电子档案移交与接收办法》执行；传统载体档案以**数字副本及目录数据**移交进馆。
