# 专题总览 05：安全保管与备份专题

## 一、档案库房建设要求（企业档案管理规定）

### 选址与布局
- 档案办公用房、阅览用房、档案库房**分别设置**；
- 库房**不宜设在地下或顶层**，湿润地区不宜设在首层；
- 不得毗邻水房、食堂（厨房）、变配电室、锅炉房、车库；
- 新建库房面积满足未来**至少 10 年**存放需要。

### 库房内部
- 不得设其他用房和明火设施；**除消防外不设给水点**；
- 楼面均布活荷载：**≥5kN/㎡**，密集架库房 **≥12kN/㎡**；
- 安装防盗门窗、视频监控、防光窗帘；**视频监控记录至少保存 6 个月**；
- 消防：洁净气体、高压细水雾等无二次损害灭火设备；
- 不宜采用水、汽为热媒采暖系统。

### "八防"清单
防火、防盗、防紫外线、防有害生物、防水、防潮、防尘、防高温、防有害气体。

## 二、温湿度要求汇总（高频数字）

### 电子档案离线载体（GB/T 18894、DA/T 78）
| 载体 | 温度 | 相对湿度 |
| --- | --- | --- |
| 光盘 | **17℃～20℃** | **20%～50%** |
| 磁性载体 | **15℃～27℃** | **40%～60%** |

- 24h 内温度变化：光盘 ≤±2℃，磁性载体 ≤±3℃（DA/T 78）；
- 24h 内相对湿度变化：≤±5%。

### 照片档案（GB/T 11821）长期贮存
| 类型 | 最高温度 | 相对湿度 |
| --- | --- | --- |
| 黑白底片 | 15℃ | 20%～40% |
| 彩色底片 | 2℃ | 20%～30% |
| 黑白照片 | 18℃ | 30%～50% |
| 彩色照片 | 2℃ | 30%～40% |

- 长期贮存 24h 温度变化 ≤±2℃、湿度 ≤±5%；中期 ≤±5℃、≤±10%；
- 中期 = 至少保存 10 年；长期 = 至少保存 100 年。

## 三、电子档案备份要求（核心数字）

### 电子档案管理办法（22 号令）——"二三"法则
- 介质：在**磁介质、光介质、缩微胶片**中选择**至少两种**；
- 数量：在线 + 离线保存**至少三套**完整数据，**每种介质一套**；
- 分工：**一套在线应用，两套备份**；
- 定期检测可读状况、软硬件环境、介质完好程度。

### GB/T 18894 备份体系
| 备份类型 | 要求 |
| --- | --- |
| 近线备份 | 宜采用**磁带备份系统**，定期全量/增量/差异备份 |
| 灾难备份 | 参照 GB/T 20988；条件许可做热备份 |
| 离线备份 | 一次写光盘、磁带、硬磁盘；**至少一套**，可 2～3 套并标识套别 |

- 载体管理：**光盘表面禁止粘贴标签**；防写处理、装盒竖立、远离强磁场强热源；
- 磁性载体**抽样检测率不低于 10%**，发现永久性误差扩大抽检或 100% 检测；
- 光盘检测超**三级预警线**立即更新；
- 自形成起**一年内**可送同级国家综合档案馆电子档案中心备份；
- 技术淘汰时立即转换介质；确认成功后对原介质**破坏性销毁**。

### 企业档案管理规定
- 备份**至少每年一次**；分级分类**异地、异质**备份；
- 重要电子档案**离线存储、一式三套**。

### 档案馆层面
- 重要电子档案**异地备份**；异地备份选址满足安全保密要求（实施条例）；
- 可建**灾难备份系统**、**电子档案备份中心**（22 号令）。

## 四、网络安全与介质要求

- 支撑电子档案管理系统的网络应与互联网**物理隔离**；与互联网设备数据传输通过**一次性写入光盘**（GB/T 18894）；
- 电子档案管理信息系统按国家等保建设，符合网络安全、数据安全、保密规定（22 号令）；
- 档案信息化基础设施：局域网、政务网、互联网；杀毒软件、防火墙等安全保障设施；
- 电子印章系统：符合密码管理、网络安全、数据安全规定；涉密信息系统按保密规定（国办 33 号文）。

## 五、档案出境管理（实施条例）

| 档案级别 | 出境要求 |
| --- | --- |
| 一级档案 | **严禁出境** |
| 二级档案 | 经**国家档案主管部门**审查批准 |
| 其他应审批档案 | 按管理权限报国家档案主管部门或省级档案主管部门批准，海关凭批准文件查验放行 |

- 涉及数据出境的还需符合数据出境规定；
- 国家所有档案及其复制件**禁止擅自出境**（档案法第 25 条）。

## 六、电子档案销毁要点

1. **程序**：编销毁清册 → 鉴定委员会（小组）审批 → 监销（清点核对、出库记录）→ 销毁清册**永久保存**；
2. **彻底性**：在线存储设备、容灾备份系统、离线存储介质中**均不可识读**；
3. **记录**：记录销毁档案的范围、数量、大小、审核人、操作者；
4. **元数据**：移入**销毁数据库**，管理过程元数据、日志自动记录；
5. **涉密**：按国家保密规定；电子档案离线介质实施**破坏性销毁**。
