# 专题总览 04：电子文件归档流程对比

## 一、四套流程总览

| 标准 | 适用对象 | 流程特点 | 归档时限 |
| --- | --- | --- | --- |
| GB/T 18894—2016 | 各门类电子文件（总纲） | 通用程序：清点、鉴定、登记、填表 | 形成后第 2 年 6 月前 |
| GB/T 39362—2020 | 党政机关电子公文 | **4 环节 12 步骤** | 整理完成后次年 6 月前 |
| GB/T 42727—2023 | 政务服务事项办件 | **两阶段**（预归档 + 正式归档） | 办结后第 2 年 6 月前 |
| DA/T 78—2019 | 录音录像档案 | 按 18894 归档程序 + 载体清点 | 形成起 3 个月内提交，最迟次年 6 月 |

## 二、GB/T 39362 电子公文归档：4 环节 12 步骤（必背）

```mermaid
graph LR
    A[文件收集] --> A1[捕获] --> A2[录入] --> A3[转换]
    A3 --> B[文件整理] --> B1[组件] --> B2[编号] --> B3[封装]
    B3 --> C[文件移交] --> C1[移交检测] --> C2[移交登记] --> C3[提交]
    C3 --> D[档案接收] --> D1[接收检测] --> D2[接收登记] --> D3[接收确认]
```

### 步骤要点速记
| 环节 | 步骤 | 关键动作 |
| --- | --- | --- |
| 收集 | 捕获 | 形成办理中随时捕获，元数据与内容一起 |
| | 录入 | 扫描著录、上传挂接、脱机导入 |
| | 转换 | 不符合归档格式的转 OFD |
| 整理 | 组件 | 以件为单位，按 DA/T 22 |
| | 编号 | 分类排序、编档号 |
| | 封装 | 封装成归档信息包 |
| 移交 | 移交检测 | 四性检测（DA/T 70），合格才提交 |
| | 移交登记 | 登记《电子文件归档登记表》 |
| | 提交 | 信息包 + 登记表一起提交 |
| 接收 | 接收检测 | 档案部门四性检测，不合格退回 |
| | 接收登记 | 清点核实、登记 |
| | 接收确认 | 接收信息包，流程结束 |

## 三、GB/T 42727 政务服务：两阶段

### 预归档阶段（业务办理部门）
文件收集 → 整理 → 清点 → 形成归档信息包 → 生成验证信息 → 归档检测 → 数据交换

### 正式归档阶段（档案部门）
接收检测 → 登记编目 → 入库

### 特色对比
| 特色 | GB/T 39362（公文） | GB/T 42727（政务） |
| --- | --- | --- |
| 基本归档单位 | 件 | **办件** |
| 信息包格式 | 归档信息包（OFD 为主） | 一个办件一个 ZIP 包，UTF-8 |
| 特殊情况 | — | **容缺归档**（标记 + 原因） |
| 变更补正 | — | **嵌套结构**新信息包替代原包 |
| 元数据 | M1～M32 基本集 | A 配置 / B 办件 / C 流程三类 |
| 数据交换 | Web Service（推送/捕获） | **数据交换目录** XML（批次） |
| 验证信息 | 封装后生成校验信息/数字摘要 | **可信时间戳、数字摘要**单独保存关联 |

## 四、归档接口对比

| 标准 | 接口方式 |
| --- | --- |
| GB/T 18894 | 三种接口：WebService、中间数据库、规范存储结构 |
| GB/T 39362 | 推送接口 putArchivingDocuments（电子公文系统）；捕获接口 getArchivingDocuments（档案管理系统）；Web Service |
| GB/T 42727 | 数据交换目录（批次 XML），随信息包传输 |

## 五、归档格式核心要求（按门类汇总）

### 通用五特性（GB/T 18894）
**格式开放、不绑定软硬件、显示一致性、可转换、易于利用**，支持向长期保存格式转换。

### 分门类归档格式表
| 门类 | 归档格式 |
| --- | --- |
| 版式文件 | PDF、PDF/A（按 DA/T 47） |
| 电子公文 | **OFD**（扫描件转**双层 OFD**） |
| 照片 | JPG、TIF |
| 录音 | WAV、MP3、AAC（采样率 ≥44.1kHz） |
| 录像 | MPG、MP4、FLV、AVI（比特率 ≥8Mbps）；珍贵加 MXF |
| 邮件 | EML |
| 网页/社交媒体 | HTML、MHT |
| 科技二维矢量 | SVG、SWF、WMF、EMF、EPS、DXF |
| 科技三维矢量 | 需永久保存转 STEP |
| 数据库文件 | ET、XLS、DBF、XML 或转版式 |
| 电子证照 | 按 GB/T 36905 版式文件形态 |

## 六、共同底线（跨标准一致要求）

1. **元数据与电子文件一并归档**；
2. **四性检测合格**（真实性、完整性、可用性 + 可靠性/安全性）；
3. **归档信息包不含非开放的压缩、加密、签名、印章、时间戳等技术措施**（39362）；
4. 归档不得采用**非开放的压缩、加密**技术（22 号令）；
5. 电子印章：归档时**去除数字签名信息，只保留印章图形**（22 号令、39362）；
6. 在线归档优先；离线归档用符合安全要求的存储介质。

## 七、记忆口诀

**公文十二步：捕录转、组编封、检登提、检登认**；
**政务两阶段：预归档七步、正式三步**；
**通用四程序：清点鉴定登记填表**；
**格式五特性：开放不绑一致可转易用**。
