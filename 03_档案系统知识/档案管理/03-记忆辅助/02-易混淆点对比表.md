## 十二、电子印章 vs 数字签名 vs 时间戳

| 概念 | 要点 |
| --- | --- |
| 电子印章 | 基于密码技术的特定格式数据，实现可靠电子签名；含图像数据、名称、所有者信息、认证证书、签名制作数据 |
| 电子签名 | 电子签章过程形成的结果数据，须真实、完整、不可否认 |
| 数字签名（元数据） | 归档元数据中的数字签名信息（DA/T 63 M68）；归档时**去除数字签名只留印章图形**（22 号令） |
| 可信时间戳 | 归档信息包验证信息的技术手段（42727、39362 可选） |
