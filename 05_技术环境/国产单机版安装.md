# 国产单机版安装

注意：系统需要打开开者模式

## 1\.第一步 部署jdk——版本（jdk\_1\.8\.0）

### 1\.1 查看自带JDK

```Plain Text
rpm -qa | grep jdk
```

### 1\.2 如已安装，请卸载

```Plain Text
rpm -e --nodeps 
```

### 1\.3 创建需要创建存放java的文件夹、推荐路径：/usr/local/soft/java

```Plain Text
#创建Java目录
mkdir java 
```

### 1\.4 将JDK压缩包放到当前目录

```Plain Text
tar -zxvf  jdk1.8.0.tar.gz
```

### 1\.5 将jdk注册到环境变量

```Plain Text
vim /etc/profile 
```

### 1\.6 在末尾添加，添加完后保存

```Bash
# 到java的安装目录
export JAVA_HOME=/usr/local/soft/Java/jdk1.8.0_361 
export CLASSPATH=${JAVA_HOME}/lib
export PATH=$${JAVA_HOME}/bin:$$PATH
```

### 1\.7 更新环境变量—使配置生效

```Plain Text
source /etc/profile
```

## 4\.第四步：配置自启动

**注意：**

- 修改 WorkingDirectory 为真实archives\-win\.jar 所在路径

- 修改 ExecStart中的jdk路径为JDK真实路径

```Bash
cd /etc/systemd/system

sudo vim archives.service

[Unit]
Description=Archives Java Application
After=network.target
[Service]
Type=simple
#工作路径，archives的文件路径
WorkingDirectory=/media/yskp/66628521216D3A3C/DAGL/
#JDK的安装路径
ExecStart=/media/yskp/66628521216D3A3C/DAGL/DAGL-BSWN/jdk-8u361-linux-x64/jdk1.8.0_361/bin/java -jar -Dfile.encoding=UTF-8 archives-win.jar --spring.config.location=my-application.yml
Restart=on-failure
RestartSec=10
[Install]
WantedBy=multi-user.target
```

## 5\.重新加载配置文件

```Plain Text
#重新加载
sudo systemctl daemon-reload
#启动服务
sudo systemctl start archives.service
#设置服务自启动
sudo systemctl enable archives-service 
```

## 6\.第六步 启动系统

### 6\.1 cd  /安装包的路径

### 6\.2 运行下面的代码

```Plain Text
java -jar -Dfile.encoding=UTF-8 archives-win.jar --spring.config.location=my-application.yml
```
